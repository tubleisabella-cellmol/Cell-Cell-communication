# Cell-Cell-communication

## Chosen sender cell and biological context

Sender cell: Fibroblast

Tissue/context: Skin dermis, wound healing

Why meaningful: Abundant connective tissue cell that coordinates repair by signaling to neighboring cells.

Ligand: CCL11 (C-C motif chemokine ligand 11)

Evidence: HPA single-cell RNA, cell type enriched in fibroblasts, tau 0.98, secreted protein class

Signaling type: paracrine

Limitation: evidence is RNA-level, and the protein was not detected in the HPA comparison panel
